# Controle de estoque

Projeto Integrador de Laboratório de Programação. Aplicação de terminal para cadastrar produtos, consultar saldos e registrar entradas e saídas.

## Como executar

Com o Python 3 instalado, abra o terminal na pasta do projeto e execute:

```sh
python estoque.py
```

No Windows, também é possível usar `py estoque.py`. O programa cria o arquivo local `estoque.json` ao salvar a primeira alteração.

## Demonstração

Cadastre um produto, registre uma entrada de 10 unidades e uma saída de 3. Uma tentativa de retirar 8 unidades deve ser recusada. Ao fechar e reabrir o programa, a listagem deve mostrar 7 unidades.
